# <img width="36" alt="App Icon" src="https://github.com/user-attachments/assets/b98a9cfa-4f9f-4693-9dfc-641d4cb95f34" /> Flutter Clean Architecture CRUD App - Day 8️⃣ 
This project was built on Day 8 of my Flutter learning journey. It's a simple CRUD app following Clean Architecture principles.

## 🛠️ Key Features
- Clean separation of concerns (Domain, Data, and Presentation layers)
- Basic CRUD functionality
- Follows best practices for scalable Flutter apps
- Clean Error Handling 

## 📦 Main Packages Used
- `flutter_bloc` - State management
- `get_it` - Dependency injection
- `http` - Networking
- `equatable` - Value comparisons for BLoC states
- `dartz` - Functional programming utilities (Either, Option, etc.)
